Stops your coding agent from booking a stadium tour to change a button color.

RockstarRouter is a skill for coding agents. Before any other skill runs, it decides how much process a request deserves: a direct fix, one focused skill, or your skill pack's full workflow.

npx skills add GregoryBabonaux/RockstarRouter
Claude Code plugin

Works with Claude Code, Codex, Cursor, Gemini CLI, GitHub Copilot and any agent that reads SKILL.md.

Skill packs have no sense of proportion

Packs like superpowers, BMAD or Spec Kit teach your agent a method: brainstorming, spec, plan, task list, review. On a real feature, that method pays off. The trouble is when it runs.

Too much

Some packs run the whole method on every request. You wait, and spend tokens, for a one-line change.

Too little

Others never start their method on their own, even for a database migration, unless you call it yourself.

Four lanes, picked for each request

RockstarRouter reads the request, checks its size, its risk and how clear it is, then picks a lane. It does not replace your pack: it decides when to use it.

QUICK
Small, clear and easy to undo. The agent finds the code, changes it and checks it. No skill.
STANDARD
A real bug, or a few files. One focused skill at most, such as debugging or TDD.
DEEP
Database schema, migration, auth, payment, several modules, new feature. Your pack's full workflow.
CLARIFY
The expected result is unclear. Two questions at most, then a lane.

If a quick change turns out bigger than expected, the agent stops and picks a new lane. To force a lane, start your message with /deep or /quick.

It tells you what it skipped

When it keeps a heavy workflow off stage, it says so in one line. The attitude stays in the chat: code, commits and pull requests stay plain.

Pick the tone with ROCKSTAR_ROUTER_TONE.

> change the primary button color to the brand blue
Edited src/public/styles.css (1 line)
🎸 superpowers:brainstorming wanted a full set-list meeting for one button. I just plugged in and played.Skipped superpowers:brainstorming: not needed for this change.

Works with packs it has never seen

No pack-specific code. RockstarRouter reads the descriptions of your installed skills: brainstorming, spec and plan skills are kept for DEEP, debugging and TDD skills can play STANDARD, and anything it cannot classify is treated as DEEP.

Install

  1. Install the skill

    /plugin marketplace add GregoryBabonaux/RockstarRouter
    /plugin install rockstar-router@rockstar-router

    Recommended. Adds the skill and two hooks: the routing rule loads at session start, and /deep and /quick are always recognized.

    npx skills add GregoryBabonaux/RockstarRouter

    For Codex, Cursor, Gemini CLI, GitHub Copilot, OpenCode and others. Installs in the project, or globally with -g.

    npx rockstar-router-cli skills --yes

    Copies the skill to ~/.agents/skills and ~/.claude/skills.

  2. Add the routing rule to your project

    npx rockstar-router-cli init

    Shows what it will write in AGENTS.md (and CLAUDE.md or GEMINI.md if your project uses them). Nothing is written until you add --yes. Optional with the Claude Code plugin.

  3. Check

    npx rockstar-router-cli doctor
